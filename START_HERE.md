# Start here

This repository contains the Astro website published at `https://www.matthiasirlbeck.com/` through GitHub Pages, observed on 5 October 2026, along with its supplied portrait, four web video renditions, posters, and both thesis PDFs. The four original videos are preserved locally and ignored by Git. Check the actual branch and working tree before continuing; the original handoff's instructions to create a new project or supply all assets have been superseded. The latest CV Advisor wording is local and has not yet been published.

1. Read [README.md](README.md) for setup and preview commands. Use Node 24, npm and the committed lockfile. On this computer, the prepared environment is available through `source ../.local/activate.sh` from the repository directory.
2. Open the local preview at `http://127.0.0.1:4321/website/` after starting it using the README. Content is editable in `src/data/` and `src/content/research/`. Keep the exact owner-approved biography and confirmed status wording unless the owner asks to change them.
3. Read [CONTENT_NOTES.md](CONTENT_NOTES.md) for sources and [CONTENT_TODO.md](CONTENT_TODO.md) for outstanding owner review and maintenance checks. Supplied assets are already integrated; unconfirmed simulation parameters and publication updates must not be invented.
4. Run the type/content checks, draft project/root and production root builds, and browser checks documented in README. Inspect desktop/mobile entries, enlarged text, keyboard controls, reduced motion and playback. Earlier Chromium/Firefox results and unresolved WebKit media limits are recorded in REVIEW_NOTES.md; validate the current revision before claiming it passes. Browser installation and successful execution are separate steps.
5. Before submitting a PR, review the actual branch and complete source/asset diff, then update [REVIEW_NOTES.md](REVIEW_NOTES.md) with current validation. The README contains the branch-specific review commands. A PR is reviewable source; it does not automatically create a GitHub Pages preview.
6. Production uses `https://www.matthiasirlbeck.com/` at `/`; `/website/` remains the local draft default. Preserve existing hosting and DNS settings. After review, only the owner authorises a merge into `main`, which triggers a production update. Verify the deployed revision and live site separately from local preview results.

The local review build includes noindex metadata but shows no visible Draft notice; production omits noindex. Noindex is not access control. Keep private drafts and residential information out of the repository. The live domain already serves the Astro site; no production-domain migration is pending in this maintenance workflow. Do not change Pages settings, DNS or publish local edits without the applicable authorization.
