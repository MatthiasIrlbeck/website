# Start here

This repository contains the working Astro review website, its supplied portrait, four web video renditions, posters, and both thesis PDFs. The four original videos are preserved locally and ignored by Git. The active implementation branch is `review/current-academic-homepage`. The original handoff's instructions to create a new project or supply all assets have been superseded.

1. Read [README.md](README.md) for setup and preview commands. Use Node 24, npm and the committed lockfile. On this computer, the prepared environment is available through `source ../.local/activate.sh` from the repository directory.
2. Open the local preview at `http://127.0.0.1:4321/website/` after starting it using the README. Content is editable in `src/data/` and `src/content/research/`. Keep the exact owner-approved biography and confirmed status wording unless the owner asks to change them.
3. Read [CONTENT_NOTES.md](CONTENT_NOTES.md) for sources and [CONTENT_TODO.md](CONTENT_TODO.md) for outstanding owner review and launch checks. Supplied assets are already integrated; unconfirmed simulation parameters and publication updates must not be invented.
4. Run the type/content checks, both base-path builds, and browser checks documented in README. Inspect desktop/mobile entries, enlarged text, keyboard controls, reduced motion and playback. The current Chromium/Firefox checks pass on both deployment paths; WebKit media checks remain unresolved on the local Linux Mint/GStreamer setup. Browser installation and successful execution are separate steps; see the recorded limits in CONTENT_TODO.md.
5. Before submitting a PR, review the actual branch and complete source/asset diff, then update [REVIEW_NOTES.md](REVIEW_NOTES.md) with current validation. The README contains the branch-specific review commands. A PR is reviewable source; it does not automatically create a GitHub Pages preview.
6. GitHub Pages is already configured for GitHub Actions at `/website/`; preserve its settings. After review, only the owner authorises a merge into `main`. Verify the deployment workflow and Pages “Visit site” before describing `https://matthiasirlbeck.github.io/website/` as live.

The review build includes noindex metadata but shows no visible Draft notice. Noindex is not access control. Keep private drafts and residential information out of the repository. The existing Google Sites site and Porkbun DNS stay unchanged; production-domain migration and removal of noindex require a separately authorised launch.
